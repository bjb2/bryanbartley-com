The codex holds every monster, item, map, skill, and status effect in the game,
each one carrying its own drop tables and stats. Click a piece of gear and it
shows you the monsters that drop it, the rate they drop it at, and the public
builds running it. The simulator goes further: allocate stats, equip and refine
gear, socket cards and substats, pick your skills, and spin a 3D preview of the
character while you work. When you finish, the Farm Plan routes you to whatever
you're still short on and sorts the targets by how long each grind takes.

It's built for the player who wants to plan a build before pouring a week into
the grind, and who has given up on drop-rate tables. Those tables never answer
the question everyone is actually asking: how long is this going to take?

## How it stays honest

Every number traces to the game's Unity export or a named community source.
Where nothing backs a value, the UI prints "no known source" or "unknown
location" and leaves the gap showing. A generator compiles the raw export into
committed data, then a verification gate runs about fifteen invariants before
each deploy. A drop table pointing at an item that doesn't exist fails the gate.
So does a map pool with a phantom monster, or an artifact piece with no listed
source. When a check fails, the deploy stops until the data is fixed.

## The Farm Plan

The planner is the part I'm proudest of. A 10% drop from a boss that respawns
once an hour is worse than a 1% drop from a mob you can kill every few seconds,
and the plan knows it. It prices each mob kill and boss attempt in seconds, adds
up the wait for everything a build still needs, and routes you accordingly.
Refine costs follow the same rule, cascading failures and downgrades included,
so the hours it quotes land close to the hours you spend.

## The social layer

A thin backend carries whatever needs server state. Save a build and share it by
link. Like and comment on other people's. Run a guild, where everyone's farming
demand pools into one view with a shared bank and squad splits. There's a
player-run auction house too: gear sells for coins, listed with its rolled
substats, a proof screenshot, and an open trade record. Pages keep their own
view counts. Builds serialize whole, so a shared link and a cloud save are the
same object. The UI ships in seventeen languages, and the Chinese was built by
hand from a community glossary.

## The arcade side

Two side modes run on the same data. Spirit Clash is a quick wave-survival
battler drawn from the game's own classes, skills, and monsters. Training
Grounds drops you onto a class against practice dummies, where you level up and
climb a damage board.

## Stack

The stack stays deliberately thin. There's no framework and no bundler. Every
page is one HTML file with its CSS and JS inline, and the game data ships as
committed JSON, generated offline from the export. A single shared stylesheet
holds every color and font token, so recoloring the whole site is one edit that
flips both dark and light. Supabase backs the social features. Cloudflare
Workers render the share-card previews and the streamer feed. The site sits on
GitHub Pages behind a deploy script that pushes, watches the build, and pokes it
again until the commit goes live.
