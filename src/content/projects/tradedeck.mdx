You open the lab. A backtest loads in the center: equity curve against
SPY, durability metrics in a strip, exit reasons broken out. The right
rail is the run history sorted by whichever metric you trust today.
Click a row to load it; ctrl-click a second to overlay the two curves
normalised at start. The daily tab takes today's bar data and emits a
manual order list formatted for Fidelity ATP, trail-stops calibrated to
the backtest.

The audience is the operator running their own money alongside an S&P 500
core, who wants the research surface and the live-deployment surface in
the same UI.

## How it stays honest

Tradedeck is a UI layer over an existing Python research pipeline.
Python owns the data, the backtester, and the order logic; SQLite is the
contract between them. The deck reads WAL-safely and only writes through
an explicit approval RPC, so the pipeline keeps running from cron and
the operator surface stays out of its way.

The trail percent each position ships with is whatever the strategy was
backtested with. The wizard locks the override out so the live sleeve
can't silently drift off the simulation.

## Aesthetic

Bloomberg terminal on purpose. Pitch ink canvas, phosphor green for
gains, crimson for losses, terminal amber as the principal voice,
JetBrains Mono everywhere data lives, zero rounded corners. P&L colors
are reserved for P&L; equity-chart slot colors are amber, info cyan, and
sterile slate, so "is this winning" never gets confused with "which line
is which".
